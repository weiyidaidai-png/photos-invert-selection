# 照片筛选工具 - Invert Selection

## 功能简介
这是一个用于筛选照片的自动化工具，能够帮助你快速整理照片库。工具会比较两个文件夹中的照片文件，并删除其中一个文件夹中与另一个文件夹重复的照片。

## 主要功能
1. **智能筛选**：自动识别两个文件夹中重复的照片文件
2. **安全删除**：仅删除待筛选文件夹中重复的文件，不影响基准文件夹
3. **多格式支持**：支持 JPG/PNG/HEIC/GIF/BMP/TIFF 等常见照片格式
4. **实时日志**：提供详细的操作日志，显示删除和保留的文件列表
5. **跨平台支持**：同时支持 Windows 和 macOS 操作系统

### 操作步骤

1. **选择基准文件夹 (A)**：
   - 点击 "浏览" 按钮
   - 选择包含你想要保留照片的文件夹
   - 这是你的 "基准" 照片库，工具不会修改这个文件夹

2. **选择待筛选文件夹 (B)**：
   - 点击 "浏览" 按钮
   - 选择包含你想要筛选照片的文件夹
   - 工具会从这个文件夹中删除与基准文件夹重复的照片

3. **开始筛选**：
   - 确认两个文件夹都已正确选择
   - 点击 "开始筛选" 按钮
   - 工具会自动开始分析和筛选照片
   - 你可以在日志窗口中看到实时的操作进度

4. **查看结果**：
   - 筛选完成后，工具会显示统计结果
   - 日志窗口会列出所有删除和保留的文件
   - 你可以点击 "导出日志" 按钮将日志保存为文本文件

## 技术说明

### 文件名匹配规则
- 工具会忽略文件扩展名进行比较（例如 "IMG_4185.jpg" 和 "IMG_4185.png" 会被视为相同文件）
- 比较是大小写不敏感的
- 支持的文件扩展名包括：.jpg, .jpeg, .png, .heic, .gif, .bmp, .tiff

### 安全保障
1. **只读基准文件夹**：工具不会修改或删除基准文件夹 (A) 中的任何文件
2. **详细日志记录**：所有操作都会被记录下来，你可以随时查看
3. **删除确认机制**：工具会在删除文件前进行严格的匹配验证
4. **错误处理机制**：如果删除文件失败，工具会记录错误信息但不会终止整个筛选过程

### 性能优化
- 工具会一次性读取所有文件信息，然后再进行比较和删除操作
- 使用集合 (Set) 数据结构进行文件匹配，确保高效的查找速度
- 支持处理包含大量照片的文件夹（数万张照片都可以轻松处理）

## 常见问题

### Q: 为什么工具无法启动？
A: 请检查以下几点：
   1. 确保已经正确安装了 Python 3.x
   2. 安装 Python 时是否勾选了 "Add Python to PATH"
   3. 尝试使用命令行方式运行，查看是否有错误信息

### Q: 工具支持哪些照片格式？
A: 工具支持以下常见照片格式：
   - JPG/JPEG (.jpg, .jpeg)
   - PNG (.png)
   - HEIC (.heic) - iOS 设备拍摄的照片格式
   - GIF (.gif)
   - BMP (.bmp)
   - TIFF (.tiff)

### Q: 为什么有些重复的照片没有被删除？
A: 请检查以下几点：
   1. 文件名是否完全相同（不含扩展名）
   2. 文件是否属于支持的照片格式
   3. 文件是否存在于待筛选文件夹 (B) 中

### Q: 我可以撤销筛选操作吗？
A: 不可以。删除操作是永久性的，无法撤销。建议在使用工具前：
   1. 备份待筛选文件夹中的重要照片
   2. 先使用少量照片进行测试
   3. 仔细检查筛选结果
